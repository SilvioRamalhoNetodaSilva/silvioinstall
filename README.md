# SilvioLinux Installer

SilvioLinux Installer é o instalador gráfico oficial do sistema operacional
SilvioLinux.

Desenvolvido em Rust utilizando FLTK 1.5.22.

## Características

- Interface gráfica rápida
- Consumo mínimo de memória
- Compatível com hardware antigo
- Instalação simples
- Código moderno em Rust
- Suporte a BIOS Legacy
- Suporte a UEFI
- Instalador modular

## Requisitos

Rust 1.90+

Cargo

FLTK 1.5.22

## Compilar

```bash
./compile.sh
```

## Instalar

```bash
sudo ./install.sh
```

## Limpar

```bash
./clean.sh
```

Executável

```
silvioinstall
```
